# Quick recipe: Serialised episode

**Looks like:** the same shot, lighting and caption template every time, numbered or dated ("Day 14", "Tip #6",
"Client question #3"). Only the topic changes, so viewers learn to come back.
**Reference:** [Gia reel](https://www.instagram.com/reel/DbDWjWvIv6k/) (Async 21/08/2026, PodcastVideos 11/09/2026).
**Use for:** an easy weekly habit; makers, product brands, "tip #N" coaches. Effort: low once set up.
**Needs:** the episode take + series name and episode number. Length 15-35 s.

## Look (sizes on a 1080x1920 frame)
| | Spec |
|---|---|
| Badge | Archivo Black, 44 px, CAPS ("TIP #6"), white on a tomato `#FF5A36` pill (or the member's accent), top-left x 60, y 140 ([Google Fonts](https://fonts.google.com/specimen/Archivo+Black)) |
| Topic line | Archivo SemiBold 56 px, ink `#141414` on an off-white `#FAF7F2` box, radius 14, under the badge at y ~230 ([Google Fonts](https://fonts.google.com/specimen/Archivo)) |
| Captions | Archivo Bold 48 px, ink on off-white box, 2-3 words, y ~1520 |
| Motion | Badge slides in from the left (0.3 s) with the signature sound; topic line pops |
| Palette | Tomato `#FF5A36`, ink `#141414`, off-white `#FAF7F2` |
| Framing | Locked: same spot, same angle, same light every episode (note it in `library-map.md`) |
| Grade | One saved look reused every time |
| Pacing | 1.1-1.3x, cut pauses only |
| Sound | A **signature sound** (one short pop or chime) on the badge every episode, the same file forever. No other SFX |

## Hook formulas
- "Tip #[N]: [the tip in 5 words]"
- "Day [N] of [challenge]: [today's thing]"
- "Client question #[N]: '[question]'"

## Presets to save in Edits
- Text: **Series badge**, **Series topic**. Captions: **Series caption**. Record the signature sound id in `library-map.md`.

## Recipe
1. First episode only: agree the series name with the member, save the presets, pick the signature sound, record
   all of it plus the episode number in `library-map.md`.
2. Every episode: same presets, positions, sound, length range and opening pattern. Bump the number.

## Do / don't
- Do put this episode's first frame next to the last one's before handing over: they must match.
- Don't restyle mid-series. Don't skip or repeat a number (check `library-map.md`).
